# TEC-Fundamentos-de-Programacion
Codigos del primer semestre

Nombre: Cual es tu edad?

Contexto: Predecir la edad de una persona basandose en sus gustos musicales. Hecho con un modelo basico de predicion usando regresion lineal alimentado de una base de datos de demografia y gustos musicales de personas, usando python, transformwes, pandas y numpy para la construccion, y con interfaz e interaccion con el usuario a travez de la consola
